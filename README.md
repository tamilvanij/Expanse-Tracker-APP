# Expanse-Tracker-APP 
The Expense Tracker is a web-based application developed using Python (Flask Framework) for backend operations, SQLite3 for database management, and HTML, CSS, and Bootstrap for frontend design. 
It enables users to record and categorize their daily expenses such as food, transport, shopping, and bills. Users can add, edit, delete, and filter entries, view summary charts, and export data to CSV for budget analysis.

The system ensures data persistence through a lightweight SQLite database. The interface is clean and responsive, allowing easy navigation across modules. The application uses dynamic Flask routes to handle user requests and connects securely with the database to store transactions. A built-in chart feature helps visualize spending by category and month, supporting financial planning.

This project demonstrates integration between backend and frontend technologies for a real-world problem – personal finance management. Future enhancements may include AI-based budget prediction, mobile-app integration, and cloud data storage.
